# Style4U — E-Commerce Web Application

Style4U is a full-stack e-commerce web application designed to offer a seamless online shopping experience for fashion and apparel. The platform features an interactive product catalog with dynamic filtering, administrator product management, and media encoding capabilities.

---

## 🚀 Features

- **Product Catalog:** Browse items dynamically filtered by categories and attributes.
- **Admin Panel:** Dedicated interface for creating, updating, and managing product listings.
- **Image Processing:** Native Base64 image encoding for efficient asset handling.
- **Responsive UI:** Clean, modern interface optimized for mobile, tablet, and desktop screens.
- **RESTful API Backend:** Fast and structured server handling CRUD operations across all resources.
